How it works

  1. Mask personal data (e-mails, phones, tax IDs, names) before anything is stored or sent.
  2. Classify each review: one theme + one severity. AI model in batches of 25 with a fixed JSON schema; keyword rules without a key.
  3. SQL (DuckDB) computes theme shares per week and the change vs the 4 previous weeks.
  4. The note is written from that facts table only; every number is checked against it (target: 0 unsupported).
  5. A person reviews the draft and the list of high-severity reviews before Monday's meeting.
