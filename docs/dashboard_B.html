How it works

  1. Collect dated snapshots of each pricing page (Wayback Machine, robots.txt checked, ~1 request / 2 s).
  2. Keep only the text around prices (plain code), then extract plans, list prices, promo prices and currency as JSON.
  3. Compare each snapshot with the previous readable one: price changed, plan added, plan not found, promo changed.
  4. Guardrails: a page without prices is 'unreadable' (never 'all plans removed'); a currency switch is 'not comparable'.
  5. Weekly digest of the latest changes, numbers checked against the extraction, links to evidence.
