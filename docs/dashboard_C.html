How it works

  1. SQL builds a facts table per client and month: revenue, orders, conversion, paid ROAS, by source, vs last month.
  2. Code detects data incidents in daily data: tracking outages, traffic spikes, conversion jumps (Poisson test).
  3. The writer (AI model or template) produces sentences with slots such as {{revenue_change_pct}}, never digits.
  4. Code fills the slots; any unknown slot or typed digit marks the report NEEDS REVIEW.
  5. The account manager edits the words and sends. Nothing is sent automatically.
